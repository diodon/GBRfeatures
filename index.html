GBR Feature Explorer — Help

How to use

  • Click any reef, island, rock, bank, cay or similar feature to see its attributes and export options in the side panel.
  • Draw › Polygon or BBox to select and export multiple features by area.
  • Labels toggle shows feature names at zoom ≥ 9.
  • Colour switches between feature-type colours and a single neutral colour.
  • Polygon geometry loads in the background after the initial centroid view — export buttons that require full geometry are enabled automatically once it is ready.

Export formats

  • Centroid — name, type, UNIQUE_ID, lon/lat (always available).
  • WKT — name, type, UNIQUE_ID, full polygon geometry as Well-Known Text.
  • BBox + Buffer — name, type, UNIQUE_ID, bounding box with optional buffer in km.
